Upload one SUM SAPupConsole.log file to get a structured breakdown of every upgrade phase — prompts shown, options offered, the option selected, and any error with its log file name. Upload two or more logs (e.g. Development, Sandbox, Quality, Production) to get a side-by-side comparison, where only the phases with a different step outcome or a different input/selection are highlighted. The system name shown for each file is read automatically from its log content. Everything runs locally in your browser — no log content is uploaded anywhere.
